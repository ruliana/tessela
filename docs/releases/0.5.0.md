## Tessela 0.5.0

The editor was rebuilt on one page model, typing got nicer, the CLI got much faster on big bundles, and a new surfacing feature brings up the note that matters while you write.

### Editor, rebuilt underneath

- One page model (sections and blocks) now drives folds, zoom, commands and select mode, instead of several parsers that could disagree. Headings own their sections, and list items own their nested code blocks, quotes and callouts. (#110-#116)
- One reveal rule: only the construct under the cursor shows its raw Markdown, and the text around it no longer jumps when marks appear or disappear. (#114, #122)
- Select mode (Esc) is rebuilt as block selection. (#117)
- Folds and selection follow your edits through block moves, so a fold stays with its block when you edit around it. Fold state is keyed by block content. (#118)

### Writing

- **Typewriter scrolling**, on by default: the line you type stays about a third of the way down the window. You can turn it off in `settings.json` (`editor.typewriter`). Focus mode gains a **sentence level**. (#123)
- **Smart paste**: a URL pasted over nothing becomes a link with the page title, HTML becomes clean Markdown, and a pasted list keeps its nesting. (#124)
- A **sticky heading path** (`Project › Design › Risks`) at the top of the editor; click a part to jump to it. Headings wrap balanced and paragraphs wrap prettier. (#121)
- Typing stays fast on long pages: about 6 ms per key at 5,000 lines, with a test that keeps it so. (#126, #130)

### Surfacing (needs a Jev key)

- **`tessela surface PAGE --at LINE`** returns the notes that bear on the block you are writing: backlinks, related pages, unlinked mentions, word matches and agenda items, each with a reason. `--whole` takes the whole page instead. (#131, #135)
- **The surface mod** shows the one note that matters in the margin at a pause, only when it is worth the interruption. Peek it, insert a link at the cursor, or press Esc to dismiss. It learns a threshold per question from what you open, link and dismiss; the numbers stay in window settings, never in your notes. (#133, #134)
- **Read next**: at the end of a page, two or three notes to go on to. (#135)
- Put your Jev key (and optionally a base URL) in the config folder's `settings.json`. With no key, every Jev feature is off and does nothing.

### Speed

Every CLI call used to parse every page. Now:

- Commands that work on one page parse one page. (#119)
- Bundle pages parse in parallel. (#127)
- Text and reference queries check raw bytes first and parse only the pages that can match. (#128)
- Unlinked mentions are found in one pass. (#120)
- Parsed pages are cached in `.tessela/cache` (rebuildable and safe to delete, not part of your notes). With a warm cache, `pages` and `related` take about 27 ms at 3,000 pages. (#129)
- `cargo bench -p tessela-cli` prints each command's time and pages parsed at 500, 1,500 and 3,000 topics, and budgets in the test suite hold the line. (#125)

### Breaking changes

Tessela is green field, so these break without shims: block entries in the CLI JSON now carry a `kind` and an end line, and the mod API reads the page through `ctx.page`. The built-in mods and the agent skill are updated.

### Fixes

- Three flaky end-to-end tests now wait on what they check. (#109, #132)
