## Tessela 0.5.1

Fixes and polish from using 0.5.0: text that jumped while you wrote, select mode that was hard to walk, scrolling that did not land where you looked, a new find box and a few layout fixes.

### Text no longer jumps while you write

- A link that turns raw while the cursor is in it holds its `](address)` under its row, so the words after it do not move or wrap again. (#146)
- Typewriter scrolling glides while you type along a line. Before, a word that wrapped onto a new row moved the whole page one row at once. (#146)
- Words no longer flip sideways between the end of a row and the start of the next when a row is full. The marks of sentence focus are only there while sentence focus is on. (#149)
- The status strip (`Saved`, `Editing…`, `New page`) and the word count keep a fixed width, so their neighbours stay put. (#146)
- Focus mode only hides the side panels: the text stays where it was, on a page and in the Journal. (#143)

### Select mode

- Down on a selected parent goes into its first child, and going Up to a parent can always be undone with Down. A walk stops only at blocks as shallow as the one it started on. (#145)
- Enter leaves select mode with the cursor at the end of the selection, like Right, and no longer adds a line. Left and Right still edit at the start and the end. (#145)
- Shift+Enter opens a line above the cursor, or above the first selected block: another item above an item, a new paragraph above a paragraph. (#145)

### Scrolling

- The typewriter line is at the golden ratio: about 62% of the way down the window instead of a third. (#147)
- Select mode shows the whole selection, starting at the typewriter line, or higher when its end would fall out of the window. A selection taller than the window shows its start. (#147)

### Find box

- Ctrl+F opens a small box over the top right corner of the page instead of a bar that pushed the text down. It uses 14 px text, shows the match count in a fixed slot (`3/12`), and has arrows and small toggles (`Aa`, `ab`, `.*`) for case, whole word and regexp. (#144)
- Replace stays hidden until you want it: Ctrl+H or Ctrl+Shift+H (Cmd+Shift+H on macOS), or the chevron. Enter in it replaces the next match. (#144)

### Layout

- A wrapped line of a list item starts under the first letter after the marker, and nested bullets sit under the text of their parent. (#148)
- A bullet whose first picture is on the marker's line is drawn as a figure: no bullet, the picture as a block, and the text on that line as its caption. (#148)
- The sticky heading bar is as wide as the editor, with an opaque background, so text no longer shows past it in the Journal. (#148)
- Numeric table columns are right-aligned. Pasting a table writes `---:` for a column of numbers, and a column with no chosen alignment is drawn right-aligned when every filled cell under the header is a number. A chosen alignment is kept, and nothing is written to the file by drawing it. (#141)

### Jev

- Jev is on when either a key or a base URL is set in the config folder's `settings.json`, for proxies that hold the key. With a base URL and no key, calls carry no `authorization` header. (#142)
- At startup, when Jev is configured, Tessela checks that it answers and tells you in the sidebar if it does not (unreachable, timeout, server error, or a key refused). A healthy service says nothing. (#142)

### Under the hood

- The speed tests count work and not time (instructions executed by a warm CLI call, steps through the syntax tree for a key), so they no longer fail on a slow runner. `valgrind` must be installed to run the CLI count; CI does. (#138, #150)
- A parallel first load of a bundle no longer loses cache entries, so a page was not parsed again on the next call now and then. (#141)
- The release workflows build the `tessela` binary before the editor tests, and a manual editor release run can attach to an existing tag. A page model test no longer depends on how fast the machine is. (#137, #139, #140)
